# BeRaw - Behance 原图批量抓取工具 v0.1.3

一个轻量侧边栏版 Chrome 扩展，用来在当前打开的 Behance 页面中提取图片、预览图片链接，并批量下载高分辨率内容。

## 功能

- 点击扩展图标后，直接打开 Chrome 侧边栏
- 只扫描当前 Behance 页面里 `img` 标签的图片资源
- 自动去重，并优先保留更高质量的候选图片
- 在侧边栏中预览、全选、取消选择
- 一键复制原图链接
- 一键批量下载到本地 `Downloads/behance-grabber/`
- 下载前可选择 `原图 / 自动 / jpg / png` 输出格式
- 将选中的图片统一打包成一个 `zip` 下载，避免 Windows 上逐张确认

## 安装方法

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前项目的 `extension` 文件夹

## 使用方法

1. 打开一个 Behance 项目页面
2. 点击扩展图标，右侧会打开侧边栏
3. 如果页面刚打开还没加载完全，可以先在页面里往下滚动，再回到侧边栏点击“刷新”
4. 选择需要的图片
5. 选择输出格式（`原图 / 自动 / JPG / PNG`）
6. 点击“下载选中图片（ZIP）”或“复制链接”

## 说明

- 这个扩展现在只抓取当前页面 `img` 标签里已经出现的图片地址，不抓 `picture`、背景图或页面脚本里的其他图片数据
- 下载按钮会先在扩展内部按所选格式处理图片，再输出一个压缩包；压缩包里是排好序的图片文件
- 选择 `原图` 时，会优先把 Behance 预览图地址推导成对应的 `source` 原图地址，再按原始字节打包；如果原图是 `webp`，会自动转成高质量 `jpg/png`
- 选择 `JPG` 时会统一导出为 `jpg`，透明区域会自动铺白底；选择 `PNG` 时会统一导出为 `png`
- 所有 `jpg` 转码都会使用当前浏览器可用的最高质量参数
- Behance 上的作品通常受版权保护，使用前请确认你有合法权限，并遵守平台条款
